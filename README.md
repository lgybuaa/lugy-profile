# lugy.me

路光越的多页面个人网站，原生 HTML/CSS/JavaScript，无构建依赖。

## 页面
首页、研究、两篇论文详情、实习经历、作品、在线简历、小游戏，以及真实404。

## 发布
Cloudflare Pages 连接本仓库 `main` 分支；构建命令留空，输出目录为 `.`。
`www.lugy.me` 作为额外自定义域名接入；默认和主域名提供相同页面，canonical 统一为 `https://lugy.me`。

## 本地预览
在仓库目录运行 `python3 -m http.server 8765`，打开 http://localhost:8765/。

## 显示和交互
主题支持跟随系统、浅色、暗色，偏好仅存当前浏览器；标签滚动可暂停且遵守 reduced-motion；
两款小游戏的最高分只在当前浏览器保存。图形记忆支持暂停、重开与自动后台暂停，最短路径使用事件驱动。
简历页可打印或保存PDF；没有将原始私人简历上传公开仓库。
