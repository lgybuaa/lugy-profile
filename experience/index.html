核销模型与序列建模

融合点击、支付、搜索等用户行为序列，用注意力与特征交叉模块增强核销倾向的表征；参与不同广告场景的实验验证，并结合效果与推理开销迭代模型。

GMV 建模与样本链路

将累计成交金额拆分为首单价值和多单残差，联合转化率任务建模；完成数据流、模型目标与线上预估策略适配，补齐缺失的支付事件训练样本。

GPU 训练与训推一致性

推进核销模型 GPU 训练迁移与训练数据链路治理，通过同样本前向对照、特征检查和模块消融定位离在线差异；结合平台协作修复与复验，不把阶段性判断当作最终结论。

长周期反馈与实验复盘

探索行业分层、节假日与退款反馈下的长周期核销纠偏，形成时序建模与数据更新方案；整理模型、实验及后续问题的交接材料。该方向在实习结束时仍处于探索与验证阶段。

最大的变化

从只看模型指标，转向一起考虑样本、特征、训练、线上预估与实验配置。先用可重复的对照缩小问题范围，再判断模型变化是否真正落地。

相似音频检索

在复杂噪声和音量差异较大的录音中处理音频预处理问题，用 FunASR 完成降噪、音频特征提取和语音转写，再用 FAISS 从音频向量中召回相似片段。对召回结果结合转写文本作进一步判别，为人工复核提供候选线索。

图像背景匹配

提取图像背景特征时，先减少人脸区域对相似度的干扰，再用 FAISS 检索相似背景。对召回的候选图像，用 LoFTR 匹配局部纹理，检查关键区域是否对应，为图像风险审核提供线索。

意图识别模块

面向销售对话场景，使用 BERT 预训练语言模型与 ChatGPT API 开发意图识别模块。模块以销售对话文本为输入，输出业务流程可以使用的意图分类结果。

业务场景适配

围绕销售场景中实际出现的表达方式优化模型，调整通用语言模型在业务意图分类中的使用方式，为后续的销售对话分析提供意图信号。
